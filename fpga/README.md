# Подмена кода без изменения содержимого FLASH без перепрошивки с помощью FPGA
![Устройство](https://github.com/trimesh33/r3dc4t/blob/main/fpga/img1.jpg)

Использована FPGA Altera Cyclone IV, подключается в разрыв линий данных D0-D3 между RP2040 и W25Q16JV, clk и cs не разрываются.
При чтении нужного адреса области памяти перенапрявлятся и перезаписыватся нужные данные патча, в остальных случаях данные проксирутся без изменений.
С помощью этого способа можно делать любые изменения кода без перепрошивки FLASH (например, если она заблокирована для записи)
